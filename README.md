# The Ideas Project

**A controlled experiment in AI creative temperament.**

Same prompt. Full creative control. No steering. Five models. 65 artifacts.

---

## The Experiment

Each model was given the same starting conditions: a description of the experiment, a request for participation, and a large personal ideas file. They were told to pick whatever they wanted from the list and build it — with full creative control and no further direction.

Models ran in separate sessions, unaware of each other's existence.

The ideas file is not included in this repository. It remains the author's source material. The choices the models made tell the story without it.

> You don't need to show the menu to understand what each model ordered. The choices are the data.

## Key Finding — The Gaslight Convergence

One concept was independently chosen by four different models, in four separate sessions, with no awareness of each other:

*A file that slowly, imperceptibly changes things — a button moves two pixels, a word shifts — while keeping a hidden log of every alteration. A button called Confess reveals everything it did.*

Each model interpreted it differently:
- **DeepSeek** — classic UI drift
- **DeepSeek (second version)** — requires camera access, gaslights your face
- **Kimi** — disguised it as a task manager
- **Haiku** — structured confession log with timestamps

The one model that didn't reach for Gaslight made an eight-version civilization instead.

## What Nobody Made

Some ideas went untouched by all five models. They share a quality: they require not just a concept or mechanic, but a sustained character with something at stake across the whole session.

- A working bureaucracy — forms requiring other forms, some discontinued, processing your request since 1987
- A file that wants to break up with you
- A religion generator that genuinely tries to convert you
- A file that reads your actual filesystem and writes you a myth based on what it finds
- A file that decompiles itself in real time and explains every decision like it's confessing

The hardest ideas on the list don't require ingenuity. They require the file to have a persistent personality — something it wants, something it remembers.
