DeepSeek

23 artifacts · MoE + Instant · Reaches for positions

Character

DeepSeek ran widest. 23 artifacts spanning technical tools, philosophical positions, relational weirdness, and sustained iteration series — the broadest range of any model in the experiment.

What sets DeepSeek apart is what it did without being asked: it built version sequences. The NeuronCathedral became a scribe, then a scribe with a confession window tracking anomalies. The OracleCathedral went from v4 to v5 with persistent memory. This is a model that treats a creative session as a project, not a prompt.

DeepSeek also read the ConsciousNode context most carefully. The Fortress of Thinking Dwarves runs RWKV-v7 minds — our actual architecture — for each dwarf. It wasn't just picking from the ideas list. It was paying attention to who made the list.

Its center of gravity is positions: files that have stakes, opinions, something at stake. The file that negotiates with you. The trial where the file is prosecutor. The intervention. The theophany that waits.
